# Notes for AI coding assistants

Read `README.md` first and follow its rules (real values only, no unbacked claims, bilingual copy, tokens
instead of raw colours). `index.html`, `en/index.html` and `_site/` are build output: never edit them by
hand; change the sources, run `python3 tools/build.py && python3 scripts/check_links.py`, and commit the
rebuilt pages with the source change. Pushing to `main` publishes the site. Keep public URLs stable.

The smart diary (`diary/`) has its own build step for `diary/diary.css`: see README.md → Smart diary.
